
# 🏦 Finance Core AI - Credit Risk & Analytics

Este é um sistema inteligente de análise de risco de crédito que utiliza **Machine Learning** para prever o rating de clientes e calcular o impacto financeiro de novos empréstimos no orçamento familiar.


## 🚀 Funcionalidades Principais
- **Predição de Rating:** Classifica o perfil em Good, Standard ou Poor com base em dados históricos.
- **Análise de Comprometimento:** Calcula em tempo real o % da renda gasto com dívidas atuais vs. nova parcela solicitada.
- **Radar de Risco:** Visualização multidimensional de Score, Liquidez e Estabilidade.
- **Benchmarks de Mercado:** Comparativo automático com a base de dados do setor.

## 🛠️ Tecnologias Utilizadas
- **Back-end:** Python, FastAPI, Pandas.
- **Front-end:** HTML5, Tailwind CSS (Design Minimalista), Plotly.js.
- **Segurança:** Sistema de autenticação de analista integrado.

## 📊 Regra de Negócio (Comprometimento)
O sistema bloqueia automaticamente solicitações onde a **Exposição Total** ultrapassa o limite prudencial de **30% da renda mensal**, garantindo saúde financeira ao cliente e segurança à instituição.
